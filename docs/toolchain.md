## 工具版本与测量边界

新工具无需与历史 VCS 精确同版本；应使用实际正反例验收，而不是凭可执行文件、帮助输出或许可条目推断能力。DC、Formality、PrimeTime PX 的当前实测版本为 O-2018.06-SP1。安装及许可配置由环境管理员维护，不是 Task 的组成部分。

PrimeTime 使用 `pt_shell` 的 averaged PX 流程。当前 `class.db` 是教学库：阈值与功耗表不完整，DBR-207 保留在记录中，internal/leakage 为零不代表真实功耗为零。面积、时序和功耗只作流程验证或固定条件下的相对测量，不进入现有功能奖励。Library Compiler 可作为未来换用经过验收的工艺库的准备路径；当前没有正式物理优化任务。

SpyGlass 缺少所需许可，不列为可用 Agent 工具。新增产品的许可条目也不等于已经完成安装与功能验收；ICC2、TetraMAX 等未接入当前任务或奖励。

## 隔离与证明的边界

Agent 的隔离探针已确认低权限 UID、进程命名空间、不可见宿主 home／评分器目录、不可改写 worker 程序、无有效 capabilities、禁止提权。网络仍用于调用模型服务；这不是完整的网络沙箱。多个试次目前共用该低权限 UID 和根文件系统，因此尚未实现试次之间的 OS 文件隔离；允许的 Agent 工具仍只读取当前试次的两份任务文件。

候选 RTL 另有受限语法检查和执行超时。当前不能把这些描述为已完成恶意编译器输入审计或所有形式的沙箱逃逸防护。

形式验证也不是“装好工具就证明正确”。必须逐条报告 proven、failed、bounded、inconclusive，说明输入假设和覆盖／非空性；综合通过也不证明协议功能正确。这些能力可以补齐，但各自需要真实运行证据。
