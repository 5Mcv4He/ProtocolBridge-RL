# 历史 VIP 审计：证据等级与项目结论

2026-11-24 的历史资源审计来自维护者提供的脱敏摘要，而非本仓库对全部产品的独立运行验收。原摘要中的 50/50 指分发文件的存在、基础完整性和可解析检查，**不表示 50 个协议已安装成功、通过仿真或构成可用 Agent 任务**。该轮没有新增商业仿真运行，也没有得到新的模型成功率或 Reward 证据。

公开能力声明应区分以下层次：

1. **资源可识别**：文件、版本标识或目录可读取；只能支持后续调查。
2. **工具可运行**：真实编译/仿真完成；仍不足以证明检查器能发现功能错误。
3. **验证器可信**：合法参考和有意义的错误对照经过独立事务检查，结果与任务契约一致。
4. **任务环境有效**：初始化、权限、公开反馈、提交及终局隔离实际验收。
5. **模型能力有证据**：固定条件的真实轨迹、有效分母、失败归因、成本与不确定性被记录。

目前正式接入的是 AXI4-Lite → APB4 任务体系，具体以[任务目录](task-catalog.md)、[质量门禁](task-quality-gate.md)和各批次原始冻结哈希及研究报告为准。完整 AXI4 或其他协议不能因资源表中出现过对应名称就标记为支持。

本页保留历史审计的来源限制与结论边界，不重复个人部署清单。历史 Git 记录和实验冻结证据不改写；介质检查明细、安装路径、许可证信息和原始运维日志只保存在可信私有记录中。
