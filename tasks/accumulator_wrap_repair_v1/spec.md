# 修复 8 位回绕累加器

这个模块保存一个 8 位无符号状态，在每个时钟沿根据控制信号装载或累加。任务考察状态更新优先级与有限位宽回绕，不要求优化面积或延迟。初始代码包含受控注入的功能错误；请交付修复后的 `accumulator.sv`。

## 完整行为契约

模块名 `accumulator`；输入 `clk, rst_n, load, enable` 均为 1 位，`value` 为 8 位；唯一输出 `q` 为 8 位。只在 `clk` 上升沿更新：

1. `rst_n=0` 时，`q_next=0`，优先于所有其他控制。
2. 否则 `load=1` 时，`q_next=value`，优先于 enable。
3. 否则 `enable=1` 时，`q_next=q+value`，采用模 256 回绕，丢弃第 9 位进位。
4. 否则保持 q。输出在两次有效时钟沿之间保持。

所有输入组合均合法，包括 load 与 enable 同时为 1。复位低有效且同步，可在任意周期重新断言。四态 X/Z、模拟时序、亚稳态、时钟门控、多时钟和 PPA 不在任务内。等价比较使用工具的二态同步 RTL 语义，对任意 8 位当前状态与输入检查上述转移，不借助“先复位”去排除状态。没有跨周期流水线或延迟容忍。

例如 q=250、value=10、enable=1、load=0、rst_n=1，下一值为 4；若同时 load=1，则必须为 10。q=127、value=1 的正常下一值为 128，不能误判为溢出。
